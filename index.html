La puerta inteligente para tu mascota

Petdoor es una puerta automática para mascotas diseñada para brindar seguridad, comodidad y control mediante sensores inteligentes y una aplicación móvil conectada.

Control desde la aplicación

Desde la aplicación móvil el usuario puede abrir o cerrar la puerta remotamente, visualizar registros y consultar la actividad de la mascota.
